# FFX Roguelite: release downloads

Installers and signed updates for FFX Roguelite, a private, non-commercial fan research project. This repository contains no
source code.

**Install:** download `FFX-Roguelite-Setup-<version>.exe` from [Releases](../../releases) and run it. After that the game's
launcher keeps itself up to date from this page at every start. No account or settings are needed.

Every release is signed; the launcher refuses any file that the project's key did not sign.
